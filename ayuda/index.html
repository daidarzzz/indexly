Ayuda de IndexLy

Gestor local de índices: carga tus archivos de juegos, libros, pelis o lo que uses, combina fuentes y busca en todo a la vez. Todo se queda en tu navegador — sin cuentas, sin servidores, sin telemetría.

1 Empezar

En la tarjeta Fuentes pulsa Añadir archivo y elige uno o varios archivos. También puedes arrastrarlos a la tarjeta o pegar datos conCtrl+V (JSON, CSV, TSV, YAML, XML o texto plano).

Cada archivo se convierte en una fuente: una lista de elementos con título, subtítulo y enlace. Todas las fuentes activas se buscan juntas, como una sola biblioteca.

Sin fuentes aún, el buscador está deshabilitado. Sube tu primer archivo y se activa solo.

2 Buscar y organizar

  • Buscador: busca en todas las fuentes activas a la vez. Ignora acentos y mayúsculas. También escribe en la URL (?q=…) para compartir la búsqueda.
  • Filtros: «Con enlace» / «Sin enlace», más los que añadan tus plugins.
  • Orden: relevancia, título A-Z/Z-A, tamaño o fecha.
  • Vistas: lista o cuadrícula. Si tienes el plugin Vistas+, el menú se amplía con Compacta, Tabla y Pósters.
  • Activar/desactivar fuentes: el interruptor de cada fuente decide si participa en la búsqueda. Con muchas fuentes, agrúpalas por paquetes del Hub.

3 Ajustar fuentes

El icono de ajustes de cada fuente abre el mapeo: renómbrala y elige qué campo de tu archivo es el título, el subtítulo y el enlace. La vista previa te dice cuántos elementos se reconocerán.

Volver a subir un archivo con el mismo nombre abre un comparador: verás qué elementos se añaden, se quitan o cambian antes de aplicar nada.

Si tienes plugins que marcan fuentes (por ejemplo «Es un índice de streaming»), esas casillas aparecen también en este modal.

4 IndexlyHub

IndexlyHub es el hub comunitario para compartir paquetes de índices. Conéctalo con un token ih_… (crea el tuyo enindexlyhub.daida.net/profile) para explorar paquetes populares, recientes, tus favoritos y buscar.

Al importar, las fuentes se agrupan en un paquete que puedes activar o eliminar en bloque. También hay una pestaña de Plugins para instalar extensiones directamente.

Explorar el Hub requiere token; instalar plugins desde la pestaña Plugins no.

5 Copia de seguridad

Exportar guarda tus fuentes seleccionadas en un único archivo (opcionalmente comprimido .gz). Importar lo restaura eligiendo qué fuentes quieres traer de vuelta. Ideal para cambiar de navegador o equipo.

Los plugins con datos propios (como GameVault) exportan desde sus Ajustes.

6 Plugins

Los plugins amplían IndexLy: secciones nuevas (como Streaming o GameVault), filtros, botones, estadísticas… Se instalan desde la tarjeta Plugins:

  • Fichero: un .js de tu equipo.
  • URL: enlaza un .js publicado en cualquier sitio.
  • Hub: pestaña «Plugins» de IndexlyHub, con versión y autor.

Al instalar verás el nombre, la versión y los permisos declarados. Los permisos son informativos salvo data:write: sin él, un plugin no puede modificar ni eliminar tus fuentes (y aun así, cualquier eliminación pide confirmación).

Cada plugin puede añadir pestañas junto al buscador (la primera, «Buscador», siempre es IndexLy). Puedes desactivar o eliminar plugins cuando quieras; desactivar recarga la página.

¿Quieres crear uno? Mira laguía para desarrolladoresy los ejemplos en /plugins/.

7 Privacidad

Todo es local. Tus fuentes, tus plugins y sus datos viven en el almacenamiento de tu navegador (IndexedDB). No hay cuentas ni telemetría. IndexLy solo toca la red cuando tú se lo pides: explorar el Hub, importar de él, o un plugin que consulte su servicio (p. ej. GameDB para GameVault).

8 Preguntas frecuentes

¿Funciona sin conexión?
Sí. Solo necesitas red para el Hub o para plugins que consulten APIs externas.
¿Dónde están mis datos?
En el almacenamiento de este navegador. Usa Exportar para llevarlos a otro sitio; cambiar de navegador o limpiar datos borra la biblioteca.
¿Por qué un plugin pide data:write?
Porque quiere poder modificar o eliminar fuentes. Tú confirmas cada eliminación y siempre puedes deshacerla.
Un plugin falla, ¿qué hago?
La tarjeta Plugins mostrará el error. Puedes desactivarlo o eliminarlo y reinstalar una versión nueva; el resto de la app no se ve afectada.
